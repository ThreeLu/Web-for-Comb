<details>
  <summary>Details</summary>

Motivation: 完美匹配是超图匹配理论的核心问题，而谱极值图论中局部谱条件（如最大度、最小度或特征值条件）与完美匹配的关系尚不完全清楚。本文填补了 $3$-graphs 和 $3$-partite $3$-graphs 在局部谱阈值方面的空白，与已有的全局谱阈值结果形成对比。

Method: 主要使用了谱图论中的特征值分析、局部谱条件（如最大度、最小度或特征值条件）以及极值构造方法。通过分析超图的邻接张量或相关矩阵的谱性质，结合组合优化技巧，推导出精确阈值。

Result: 对于 $3$-graphs，证明了当最小度 $\delta(G) \geq \lfloor n/2 \rfloor$ 或最大度 $\Delta(G) \leq \lceil n/2 \rceil$ 等局部谱条件满足时，$G$ 包含完美匹配；对于 $3$-partite $3$-graphs，给出了类似的精确阈值，例如 $\delta(G) \geq \lfloor n/2 \rfloor$ 或 $\Delta(G) \leq \lceil n/2 \rceil$。这些阈值是紧的。

Conclusion: 本文的结果为超图完美匹配的局部谱条件提供了精确刻画，推广了之前关于全局谱阈值的工作，并揭示了局部谱参数与匹配存在性之间的紧密联系。

Future Work: 论文可能提出了将结果推广到 $k$-graphs（$k \geq 4$）或更一般的超图类，以及探索其他局部谱参数（如特征值）的阈值问题。

### [2] [Limitations of the slice rank method in additive combinatorics](https://arxiv.org/abs/2609.27044)
*Sankeerth Rao Karingula, Shachar Lovett*

Main category: math.CO

TL;DR: 本文证明了 slice rank method 在 additive combinatorics 中的若干局限性，构造了 slice rank 远大于其实际 combinatorial 复杂度的张量，并给出了 slice rank 与 partition rank 之间的分离。


<details>
  <summary>Details</summary>

Motivation: slice rank method 是 Croot–Lev–Pach 和 Ellenberg–Gijswijt 解决 cap set 问题后发展出的重要工具，被广泛用于 additive combinatorics 中的上界证明。然而，该方法的能力边界此前并不清楚，本文旨在系统研究其局限性，回答 slice rank 何时会失效的问题。

Method: 作者结合了代数构造与组合论证，通过显式构造具有小 partition rank 但大 slice rank 的张量，并利用多项式方法（polynomial method）和 rank 的代数性质进行分析。

Result: 主要结果包括：构造了 slice rank 为 $\Omega(n)$ 但 partition rank 仅为 $O(1)$ 的张量，从而证明 slice rank 与 partition rank 之间存在指数级分离；此外还给出了 slice rank method 在若干 additive combinatorics 问题中无法给出非平凡上界的例子。

Conclusion: 这些结果说明 slice rank method 并非万能，其成功依赖于问题的特定代数结构；对于某些问题，需要更强的工具如 partition rank 或更高阶的代数方法。

Future Work: 论文提出了若干开放问题，包括能否进一步改进 slice rank 与 partition rank 的分离下界，以及是否存在其他组合问题中 slice rank method 失效但 partition rank 有效的例子。

Future Work: 论文可能提出将结果推广到禁止 $K_{s}$（$s \ge 5$）的多部图，或研究非完全多部图（如带有额外边约束）的色极值阈值。另一个自然方向是确定更一般的色临界图在多部情形下的极值阈值。

### [7] [A General Upper Bound on Multicolor Ordered Ramsey Numbers](https://arxiv.org/abs/2609.28075)
*Martin Balko, Klára Grinerová*

Main category: math.CO

TL;DR: 本文给出了多色有序 Ramsey 数 $\tilde{r}_k(G_1,\dots,G_k)$ 的一个一般上界，该上界由各图的有序路径覆盖数（ordered path cover number）和顶点数决定。


<details>
  <summary>Details</summary>

Motivation: 有序 Ramsey 数是经典 Ramsey 数在顶点有序图上的推广，近年来受到广泛关注。此前对多色有序 Ramsey 数的上界主要针对特定图类（如匹配、路径、圈）或依赖于更复杂的参数，缺乏一个统一且易于计算的一般性上界。本文填补了这一空白，给出了一个适用于任意 $k$ 个有序图的一般上界。

Method: 作者引入了有序路径覆盖数（ordered path cover number）这一参数，并利用有序图的路径分解结构，通过构造性的嵌入论证来证明上界。方法结合了有序 Ramsey 数的基本性质与路径覆盖的计数技巧。

Result: 设 $G_1,\dots,G_k$ 为 $k$ 个有序图，$n_i=|V(G_i)|$，$\rho(G_i)$ 为 $G_i$ 的有序路径覆盖数。则 $$\tilde{r}_k(G_1,\dots,G_k) \le \sum_{i=1}^k (n_i-1) \prod_{j=1}^{i-1} \rho(G_j) + 1.$$ 该上界在若干情形下与已知结果匹配或改进。

Conclusion: 该结果统一并推广了多色有序 Ramsey 数的若干已知上界，为研究有序 Ramsey 数提供了一个简洁而通用的工具。它表明有序路径覆盖数是控制有序 Ramsey 数增长的关键参数。

Future Work: 论文可能提出了若干开放问题，例如该上界在特定图类（如匹配、路径、圈）上是否紧，以及能否通过更精细的参数（如有序树覆盖数）进一步改进上界。一个自然的延伸是研究下界构造，以确定该一般上界的紧性。
