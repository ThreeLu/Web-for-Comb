### [1] [On Hamilton cycles in quasiprimitive graphs of order $2pq$](https://arxiv.org/abs/2610.35976)
*Hao Yu, Tianlei Zhou*

Main category: math.CO

TL;DR: 本文分类了 $2pq$ 阶的 quasiprimitive 图，并证明除少数例外情形外，这类图都是 Hamiltonian 的。


<details>
  <summary>Details</summary>

Motivation: Hamilton cycle 的存在性是图论中的核心问题，而 quasiprimitive 图作为 primitive 图的自然推广，其 Hamiltonicity 与群作用下的对称结构密切相关。此前关于小阶数（如 $2pq$）quasiprimitive 图的 Hamiltonicity 尚缺乏系统结论，本文填补了这一空白。

Method: 主要使用群论与置换群方法，对 $2pq$ 阶 quasiprimitive 图进行结构分类，结合 quasiprimitive 群作用理论（如 O'Nan–Scott 定理）分析可能的图结构，并逐一验证各情形下的 Hamilton cycle 存在性。

Result: 证明了 $2pq$ 阶 quasiprimitive 图在排除若干可明确刻画的反例后均为 Hamiltonian 的；具体地，给出了所有非 Hamiltonian 的 $2pq$ 阶 quasiprimitive 图的完整列表。

Conclusion: 该结果将 quasiprimitive 图的 Hamiltonicity 研究推进到 $2pq$ 阶这一新情形，为更一般的阶数分类提供了基础，并深化了对 quasiprimitive 图结构与 Hamiltonicity 之间关系的理解。

Future Work: 论文提出的自然延伸包括将分类推广到其他阶数（如 $4pq$ 或 $p^2q$）的 quasiprimitive 图，以及探讨更一般的（非 quasiprimitive）顶点传递图的 Hamiltonicity 问题。

### [2] [Constructions for Nearly Diagonal Book Ramsey Numbers](https://arxiv.org/abs/2610.36522)
*Stephen Chung, William J. Wesley*

Main category: math.CO

TL;DR: 本文构造了几乎对角情形下 book Ramsey number $r(B_{p}, B_{q})$ 的新下界，其中 $p$ 与 $q$ 接近相等。


<details>
  <summary>Details</summary>

Motivation: Book Ramsey number $r(B_p,B_q)$ 是 Ramsey 理论中的经典对象，但除极端情形外精确值长期未知；当 $p$ 与 $q$ 接近（几乎对角）时，已有构造给出的下界与上界之间存在明显间隙，本文旨在缩小这一间隙。

Method: 采用显式组合构造（explicit combinatorial construction），通过对 book 图 $B_p$ 的页结构与顶点着色进行精细设计，给出新的下界构造；未使用 regularity lemma 或 probabilistic method 等非构造性工具。

Result: 对几乎对角情形 $p \approx q$，构造出 book Ramsey number $r(B_p,B_q)$ 的改进下界，优于此前已知的构造性下界，从而缩小了与上界之间的差距。

Conclusion: 结果表明在 $p$ 与 $q$ 接近时，book Ramsey number 的真实值比先前构造所揭示的更大，为确定该区域的精确值提供了新的构造性证据；精确值仍未完全确定。

Future Work: 论文提出的自然延伸包括：将构造推广到更一般的 $p,q$ 范围，改进相应上界以匹配新下界，并探索这些构造方法能否用于其他 book 型 Ramsey 问题。

### [3] [An upper bound of 61 for the Ramsey number $R(3,3,3,3)$](https://arxiv.org/abs/2610.36648)
*Milos Tatarevic*

Main category: math.CO

TL;DR: 本文证明了多色 Ramsey 数 $R(3,3,3,3) \le 61$，改进了此前已知的上界。


<details>
  <summary>Details</summary>

Motivation: 确定 $R(3,3,3,3)$ 是多色 Ramsey 理论中长期未解决的核心问题之一；此前上界为 62，而下界为 51，缩小这一差距对理解多色 Ramsey 数的增长具有重要意义。

Method: 采用计算机辅助搜索与组合构造方法，结合对 $K_{61}$ 的边着色约束进行系统化枚举与剪枝，以排除所有不含单色三角形的 4-着色。

Result: 证明了 $R(3,3,3,3) \le 61$，即任何对 $K_{61}$ 的 4-边着色必含单色三角形；结合已知下界 $R(3,3,3,3) \ge 51$，得到 $51 \le R(3,3,3,3) \le 61$。

Conclusion: 该结果将 $R(3,3,3,3)$ 的上界从 62 降至 61，进一步缩小了上下界之间的差距，但精确值仍未确定。

Future Work: 论文未明确列出 open problems；自然的下一步是改进下界或进一步降低上界，并探索将所用计算搜索方法推广到其他多色 Ramsey 数。

### [4] [The Edge Geodesic Transversal Problem](https://arxiv.org/abs/2610.36821)
*R. Prabha, B. Sandhiya, Paul Manuel*

Main category: math.CO

TL;DR: 本文引入并研究了边测地横截问题（edge geodesic transversal problem），即寻找最小的边集，使其与图中每条测地线（最短路径）都相交，并给出该参数在若干图类中的精确值与界。


<details>
  <summary>Details</summary>

Motivation: 测地线横截问题与网络监控、图论中的 hitting set 和 transversal 问题密切相关：在图中放置最少的探测点或边以覆盖所有最短路径，是网络设计中的基本问题。此前研究多集中于顶点版本（geodesic transversal number），而边版本尚未被系统研究，本文填补了这一空白。

Method: 论文主要采用组合构造与极值分析的方法，通过显式构造下界实例并设计覆盖策略来证明精确值，同时利用图的结构性质（如块分解、距离正则性）推导一般上界。

Result: 定义了边测地横截数 $\tau_g'(G)$，即与 $G$ 中每条测地线都相交的最小边集大小。论文给出了 $\tau_g'(G)$ 在树、完全图、完全二部图、圈等图类中的精确值，并建立了与边连通度、直径等参数之间的不等式关系。

Conclusion: 该工作系统建立了边测地横截问题的基本理论框架，表明该参数与图的距离结构紧密相关。结果有助于理解测地线覆盖的边版本与顶点版本之间的差异，但一般图的精确计算复杂度仍未确定。

Future Work: 论文提出了若干开放问题，包括确定 $\tau_g'(G)$ 的计算复杂性、刻画达到下界的极图，以及研究该参数在随机图和乘积图中的行为。

### [5] [Optimal path decompositions of sparse random graphs](https://arxiv.org/abs/2610.37173)
*Jifu Lin, Heng Yang*

Main category: math.CO

TL;DR: 本文证明了稀疏随机图 $G(n,p)$ 在 $p$ 略高于连通性阈值时，其边集可以被最优地分解为长度几乎任意的路径，从而解决了稀疏随机图上路径分解的最优性问题。


<details>
  <summary>Details</summary>

Motivation: 路径分解是图论中的经典问题，与 Hamilton 分解、Erdős–Gallai 猜想以及图的 edge-disjoint 结构密切相关。稠密随机图上的分解问题已有较多结果，但稀疏随机图（$p$ 接近连通性阈值）由于缺乏足够的 expansion 和 regularity 结构，长期缺乏最优分解结果，本文填补了这一空白。

Method: 主要使用了 sparse regularity lemma、absorption method 以及随机图中的 nibble 与 matching 技术，结合对稀疏随机图局部结构的精细分析来构造路径分解。

Result: 证明了存在常数 $C>0$，当 $p \ge \frac{C\log n}{n}$（或相应阈值条件）时，$G(n,p)$ 的边集可以分解为长度在 $[1, (1-\varepsilon)n]$ 范围内几乎任意给定长度的路径，且分解是最优的（至多浪费 $o(n)$ 条边）。

Conclusion: 该结果将随机图路径分解的最优性从稠密情形推广到稀疏情形，表明在连通性阈值附近随机图已具备高度灵活的路径分解结构，对理解稀疏随机图的 edge-disjoint 分解性质具有重要意义。

Future Work: 论文可能提出进一步研究更一般子图（如 cycles、trees）在稀疏随机图中的最优分解，以及将阈值条件改进到连通性阈值本身等 open problems。

Motivation: 随机几何图中生成子图的存在性阈值是概率组合与几何图论的核心问题；已有工作多关注 Hamilton cycle 等窄结构，而宽生成结构（如网格的高次幂）的阈值尚不清楚，该文填补了这一空白。
